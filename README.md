# 📥 DWvideos — Clipboard Video Downloader

Panoya kopyalanan video bağlantılarını anlık yakalayan ve tek tıkla indiren pratik masaüstü aracı.

## ✨ Özellikler
- **Otomatik Yakalama:** Kopyaladığın video linkleri anında listeye eklenir.
- **Platform Desteği:** YouTube, TikTok (filigransız ve sesli), Instagram ve daha fazlası.
- **Format Seçenekleri:** 1080p, 720p, 480p veya Sadece Ses (MP3).
- **Konumu Göster:** İndirilen videoyu Windows Gezgini'nde doğrudan seçili halde açma.
- **Özel İndirme Dizini:** İndirilen dosyaların kaydedileceği klasörü kolayca değiştirme.
